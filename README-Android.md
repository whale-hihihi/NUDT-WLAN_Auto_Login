# 校园网自动登录 - 安卓版

与电脑版同一套深澜(SRun)协议(HMAC-MD5 + SHA1 + XXTEA + 自定义base64)，
加密算法经 PC 端 Python 实现生成的参考向量逐字节验证一致。

## 功能

- 手动: 打开 App → 「检测状态」查看当前状态 → 「立即登录」一键认证
- 自动: 开启「自动登录」开关后, WiFi 断线重连/开机时自动登录(WorkManager, 无常驻进程, 已联网时亚秒级结束)
- 正确处理"移动数据与 WiFi 同开"场景: 所有探测与登录请求强制绑定 WiFi 网络, 不会被 5G 误判
- 认证服务器/账号密码可改, 适配其他学校深澜门户

## 安装(各品牌通用)

1. 把 `校园网自动登录.apk` 传到手机(微信/QQ/USB均可)后点击安装, 允许"未知来源"
2. 打开 App, 填账号密码 → 保存配置 → 开启「自动登录」开关
3. **关键一步: 后台白名单**(国产 ROM 必须, 否则后台任务会被系统推迟):
   - vivo/iQOO (OriginOS): 设置 → 电池 → 后台耗电管理 → 本应用 → 允许后台高耗电;
     设置 → 应用 → 应用启动管理 → 本应用 → 关闭"自动管理", 打开自启动/关联启动/后台弹窗
   - OPPO/一加 (ColorOS): 设置 → 应用 → 本应用 → 电池 → 允许完全后台行为; 自启动打开
   - 荣耀 (MagicOS): 设置 → 应用 → 应用启动管理 → 本应用 → 手动管理, 全部允许; 电池 → 不受限
4. 点「立即登录」测试一次

## 账号密码配置

打开 App，账号密码就是**浏览器登录校园网时输入的那组账号密码**：
「账号」「密码」输入框填入 → 点「**保存配置**」→ 点「立即登录」测试。
以后改密码同样操作，重新保存一次即可（数据存在应用私有目录，卸载即清除）。

「认证服务器」和「ac_id」两个输入框保持默认（NUDT 为 `http://10.20.69.103` / `3`）；
其他学校按 [主 README 的适配说明](README.md#%EF%B8%8F-配置说明账号密码) 修改。

## 验证自动重连

WiFi 关闭再打开(或走出教室再回来), 1 分钟内 App 日志应出现
`触发[网络变化] 检测开始 → 登录响应: login_ok → 登录成功, 已联网`。

## 说明

- 密码明文存在应用私有目录(/data/data), 卸载即清除
- 部分手机"WiFi 掉线后不自动重连"是 ROM 的 WiFi 策略, 需手动连一次 WiFi; App 负责之后的认证全自动
- 日志: App 内可直接查看, 文件位于应用私有目录 files/login.log

## 工程结构(android-app/)

| 文件 | 作用 |
|---|---|
| `SrunCrypto.kt` | XXTEA/自定义base64/HMAC-MD5/SHA1(与 PC 版 srun.py 等价) |
| `SrunApi.kt` | HTTP 协议层 + WiFi 网络绑定(避免走蜂窝) |
| `LoginEngine.kt` | 检测→登录→验证 编排 |
| `LoginWorker.kt` | WorkManager 后台: WiFi触发自续链 + 15分钟兜底 |
| `BootReceiver.kt` | 开机/应用更新后恢复任务 |
| `MainActivity.kt` | Compose 界面 |
| `SrunCryptoTest.kt` | 跨语言一致性单元测试(向量来自 Python) |

构建: `cd android-app && gradlew.bat assembleDebug`(JDK17, 依赖走阿里云镜像)
